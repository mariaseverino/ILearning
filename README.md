# 🎓 I Learning

O **ILearning** é uma plataforma de ensino e cursos online desenvolvida para oferecer uma experiência de aprendizado intuitiva e completa. O objetivo é conectar alunos a um vasto catálogo de cursos e permitir que gerenciem seu progresso e perfil de forma eficiente.

## ✨ Telas Principais

A plataforma conta com as seguintes seções e funcionalidades já implementadas:

-   **Meu Perfil:** Visualize e gerencie suas informações pessoais, como nome, e-mail e configurações de conta.
-   **Meus Cursos:** Acesse todos os cursos em que você está matriculado, acompanhe seu progresso e retome seus estudos de onde parou.
-   **Catálogo:** Explore uma variedade de cursos disponíveis, com opções de busca e filtros para encontrar o aprendizado ideal para você.
-   **Configurações:** Ajuste as preferências da sua conta, notificações e outras configurações da plataforma.

## 🧰 Tecnologias Utilizadas

Este projeto é construído com tecnologias modernas para garantir performance e manutenibilidade:

-   **TypeScript:** Para um código mais robusto, tipado e escalável.
-   **React:** Para a construção da interface de usuário dinâmica e reativa.
-   **React Router:** Para o gerenciamento de rotas e navegação na aplicação.
-   **TailwindCSS:** Para uma estilização rápida e eficiente da interface.

## 🚀 Como Executar o Projeto (Desenvolvimento)

Para ter o ILearning rodando em sua máquina, siga os passos abaixo:

1.  **Clone o repositório:**

    ```bash
    git clone https://github.com/mariaseverino/ILearning.git
    cd ILearning
    ```

2.  **Instale as dependências:**

    ```bash
    npm install
    # ou yarn install
    ```

3.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    # ou yarn dev
    ```
    O aplicativo estará disponível em `http://localhost:5173`.
